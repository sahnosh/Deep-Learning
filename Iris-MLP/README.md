# Iris Classification with a PyTorch MLP

A beginner neural-network project that classifies three Iris species from four measurements using a 4-16-8-3 MLP. It covers train/validation/test splits, standardization, training, learning curves, a classification report, and a confusion matrix.

Open [Iris_Classification_PyTorch_MLP.ipynb](Iris_Classification_PyTorch_MLP.ipynb) in Jupyter or Google Colab and run the cells in order. Requirements: PyTorch, NumPy, pandas, scikit-learn, and Matplotlib. The dataset is bundled with scikit-learn; the notebook explicitly uses CPU in Step 7.

The saved 100-epoch run achieved **90% test accuracy (27/30)** with 90 training and 30 validation samples. This is a previously recorded result; the small test set limits generalization claims.
